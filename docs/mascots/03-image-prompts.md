# Image Generation Prompts (Higgsfield)

Ready-to-run prompts for concept images of each mascot, built from the
character sheets. These are concept references for the 3D artist, not final
assets.

Settings: model `gpt_image_2_6`, aspect ratio `16:9`, one image per mascot.

## How to build a prompt

Join the three parts in this order: **OPENING** + the mascot's **IDENTITY** + **TAIL**.

### OPENING (same for all)

```
Character turnaround model sheet, four consistent full-body views in a row — front view, 3/4 view, side profile, and back view, evenly spaced, identical original kawaii mascot on all views, pure white seamless studio background, professional character sheet presentation, tiny plush-toy scale chibi character about 2 heads tall with the head half of the total height, stubby mitten limbs with no fingers, large glossy dark-brown oval eyes set low and wide apart with one big highlight and one small highlight, soft pink blush ovals on the cheeks, tiny simple mouth,
```

### TAIL (same for all)

```
stylized 3D character render in a soft matte clay and plush toy look, smooth rounded shapes, no realistic fur strands or scales or feathers, subsurface scattering on ears and cheeks, soft global illumination, three-point studio lighting with warm key light, gentle rim light, soft contact shadow, high-end 3D animation studio quality, pastel palette, 4K, single original character that does not resemble any existing film, game or toy character, no clothing unless described, no extra characters, no text, no watermark, no logos, no frame borders
```

## Follow-up images per mascot

Once a turnaround is approved, use it as a reference image and change only the
OPENING to one of these:

- **Phase poses:** `Four-panel character sheet of the same character in four poses side by side:` followed by the four pose descriptions from the character sheet.
- **Expression sheet:** `Character expression sheet, one full-body reference on the left and a grid of head portraits on the right showing neutral, happy, sad, sleepy, pouty, surprised and loved expressions,`
